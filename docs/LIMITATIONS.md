# Limitations

This is a synthetic portfolio demonstration, not production software.

- Local tests used SQLite in memory.
- PostgreSQL integration was not tested in this laboratory.
- Authentication, authorization and multi-tenancy are not implemented.
- No load, penetration or browser E2E tests were performed.
- FastAPI TestClient emitted one Starlette deprecation warning.
- Dependency versions are bounded but not fully locked.
- GitHub Actions has not yet been executed and verified.
- A clean local rebuild passed; dependency versions are not fully locked for future identical resolution.
- Coverage describes the measured app module only.
- A passing test suite does not prove absence of defects.
