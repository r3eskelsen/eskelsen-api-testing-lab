# Python API Testing & Automation Lab

Independent QA automation portfolio demonstration by Eskelsen Systems.

Designed and executed a structured pytest-based testing laboratory for
a synthetic FastAPI inventory REST API.

The work includes isolated database fixtures, CRUD functional tests,
input validation, HTTP response contract verification, negative cases,
regression testing and branch coverage analysis.

Verified locally on Windows with Python 3.12:
45 passing tests and 100% measured line/branch coverage of app/main.py.

Tools: Python, pytest, FastAPI TestClient, HTTPX, SQLAlchemy,
SQLite and pytest-cov.

The project uses no customer systems or real customer data.
GitHub Actions configuration is included for subsequent verification.

This is an independent technical demonstration, not a claim of
production deployment or third-party certification.
